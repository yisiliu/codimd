# Design Context

## Product
CodiMD adapted as a closed, invite-only collaborative notes tool for a single **research institute** (~3 teachers/admins + ~20 graduate students). Self-hosted. The custom surfaces (added on top of CodiMD) are: the signed-in **dashboard** (My Notes + Browse), the **admin** panel, **invite** redeem/invalid pages, the **sign-in** modal, and the editor **comments** panel.

## Audience
Working academics — faculty and grad students. Comfortable with tools, value clarity and speed, on desktop and mobile. Daily use.

## Jobs to be done
Write/organize markdown notes; share notes into course/lab **spaces**; hand out read-only material and make student copies + templates; leave line-anchored **feedback comments**; manage members/roles/invites.

## Brand personality / tone
**Editorial / academic.** Confident and scholarly, like a well-set journal — not "techy", not playful, not corporate-SaaS. Distinctive display typography, a single strong warm accent on tinted (warm) neutrals, real typographic hierarchy, generous whitespace, hairline rules instead of boxy cards. Bold via type + contrast + rhythm, not effects. **Intensity = confident refresh** (strong identity, still calm for daily institutional work).

## Design language (the system)
- **Type:** `Fraunces` (variable serif, optical sizing) for display/headings + brand; `Hanken Grotesk` for UI/body. No Inter/Roboto/system, no mono-as-decoration.
- **Color:** warm "paper" neutrals (never pure #fff/#000), warm near-black ink, one dominant **terracotta/brick** accent; semantic sage (shared), ochre (template), ink-blue (tags). Tinted neutrals. Works in light + the existing **dark mode** (warm charcoal + cream).
- **Layout:** an editorial **masthead** as the hero; rule lines over card-nesting; varied rhythm; left-aligned, asymmetric where it helps; flatten card-in-card.
- **Motion:** restrained — a single subtle staggered entrance, calm hover states, `ease-out` (no bounce/elastic).
- **Constraints:** must not break CodiMD's editor bundle or the JS class hooks (`.dash-note`, `.folder-list`, etc.) — reskin via CSS + design tokens, keep the DOM/JS contract. Keep WCAG-AA contrast.

## Anti-slop guardrails
No purple→blue gradients, no glassmorphism, no neon-on-dark, no gradient text on headings/metrics, no identical card grids, no big rounded icons above headings.
